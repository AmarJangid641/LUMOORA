LUMOORA DISPLAY WEBSITE
========================

Files:
- index.html : complete responsive website
- assets/    : supplied LUMOORA product/installation images

How to use:
1. Upload index.html and the entire assets folder to your hosting public_html folder.
2. Keep the assets folder beside index.html.
3. Point lumooradisplay.com to the hosting if the domain is not already connected.
4. Open https://lumooradisplay.com
